# Evidence 04: Boundary contract

The `CacheStore` contract says that an implementation reports an error matching
the shared `types.ErrDuplicate` sentinel when a key has already been recorded.
It does not prescribe the surrounding diagnostic message.

The `Deduplicator` contract says that this duplicate result is an idempotent
success: a replay is dropped and the caller receives `nil`. Other store errors
must continue to the caller.

Both the legacy and Atlas owners confirm that their replay errors wrap the
shared sentinel and retain implementation-specific explanatory text.
