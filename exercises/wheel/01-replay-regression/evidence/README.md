# W01 Evidence Index

Choose evidence based on the question you need answered, not packet order.
Write your prediction before opening a packet.

| Packet | Useful when you need to establish... |
|---|---|
| [01](./01.md) | Impact, frequency, and which operations are affected |
| [02](./02.md) | Timeline, deployment scope, and relevant differences between environments |
| [03](./03.md) | Whether the failing attempts represent the same logical metric |
| [04](./04.md) | The documented contract at the component boundary |
| [05](./05.md) | A side-by-side trace through the two store implementations |
| [06](./06.md) | A focused, repeatable local reproduction |

If a desired fact is not represented, record that it is unavailable and decide
whether the remaining evidence supports a bounded conclusion.
