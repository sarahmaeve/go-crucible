# Evidence 02: Timestamp Distribution

A ten-minute incident burst contained 18,420 alerts:

```text
distinct stored timestamps                 6,107
alerts sharing a timestamp with a peer    14,996
largest equal-timestamp group                 83
configured page size                          50
```

The timestamps originate from batched upstream observations and are stored at
millisecond precision. Increasing precision would not make events from one
batch unique, and increasing the page size would only move the boundary.

How large must one equal-timestamp group be relative to the page size to
guarantee that a page boundary falls inside the group?
