# Evidence 02: Number of timestamp ties

A ten-minute incident burst contained 18,420 alerts:

```text
distinct stored timestamps                 6,107
alerts sharing a timestamp with a peer    14,996
largest equal-timestamp group                 83
configured page size                          50
```

The timestamps come from batched upstream observations and use millisecond
precision. More precision would not make events from one batch unique. A larger
page would only move the boundary.

How large must a tied group be, compared with the page size, to guarantee that a
page boundary falls inside it?
