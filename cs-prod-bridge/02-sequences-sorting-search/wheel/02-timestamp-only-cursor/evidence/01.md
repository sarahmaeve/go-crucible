```text
next after=12:00:00.000

request 2 after=12:00:00.000
response IDs=108,107,109 timestamps=11:59:00.000,11:59:00.000,11:58:00.000
next after=<none>
```

Direct lookups for IDs 104, 105, and 106 succeed. All three belong to the
same frozen snapshot and have timestamp `12:00:00.000`.

The stated order does not yet say how to arrange incidents with equal
timestamps. Mark the equal-timestamp group, then state which additional field
and ordering rule would let the cursor distinguish every member from the last
