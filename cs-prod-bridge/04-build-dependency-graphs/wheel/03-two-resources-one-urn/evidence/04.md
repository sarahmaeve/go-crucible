# Evidence Packet 4: Deletion rule and production source

For the local edge `B -> A`, record B depends on record A. If both are removed,
deletion must remove B before A. Removing A first would leave B referring to a
resource that no longer exists.

[Pulumi PR #19179](https://github.com/pulumi/pulumi/pull/19179), merged in April
2025, documents a permitted snapshot with current A, B depending on A, and an
older A marked for deletion. A dependency lookup keyed only by URN associated B
with the deleted A. Later deletion code could then allow removal of the current
A and leave B pointing to a resource that no longer existed. The patch kept
current resources and resources waiting for deletion separate while building
the graph.

The local record IDs, types, preview API, counts, and examples are invented.
They focus on the identity and ordering problem. They do not reproduce Pulumi's
resource graph.
