# Evidence Packet 3: The same records in two input orders

The graph builder receives the same three records in two orders:

| Arrival order | Record chosen for `service-current -> urn:database` |
|---|---|
| current database, service, old database | `database-old` |
| old database, service, current database | `database-current` |

The record contents do not change. Only their positions in the input slice
change.

The public plan promises the same output for snapshots with the same records.
