# Evidence Packet 4: Production source and local boundary

[Prometheus PR #15560](https://github.com/prometheus/prometheus/pull/15560),
merged in December 2024, describes a rule-dependency controller for which an
empty dependency map made affected rule groups look as though they had no
dependencies or dependents. When the system could evaluate rules at the same
time, it could do so even when it had not determined their dependencies.

That upstream change inspired the distinction tested here. The local target
names, `Analysis` and `Plan` types, counters, scheduling rules, and error text
are invented. The exercise does not reproduce Prometheus rule evaluation.
