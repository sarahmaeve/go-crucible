# Evidence Packet 4: Loader rules

The loader accepts an endpoint IP and returns ownership metadata:

```text
LoadEndpoint(ip) -> {owner, region}
```

During the lifetime of one resolver, repeated loads for the same IP return the
same value. A metadata update builds a new resolver and publishes it atomically.
The current component therefore does not need time-based refresh.

The observation timestamp affects event order later in the system. It does not
affect the endpoint ownership lookup.
