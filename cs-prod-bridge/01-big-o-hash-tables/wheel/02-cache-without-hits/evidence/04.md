# Evidence Packet 4: Loader contract

The loader accepts an endpoint IP and returns ownership metadata:

```text
LoadEndpoint(ip) -> {owner, region}
```

Within the lifetime of one resolver, repeated loads for the same IP return the
same value. Metadata publication constructs and atomically publishes a new
resolver, so the current component does not need time-based refresh.

Observation timestamp affects event ordering downstream but does not affect
endpoint ownership lookup.
