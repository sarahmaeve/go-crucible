# Unit 03: Queues, Heaps, and Scheduling

Read the lesson source here, or run `make bridge-serve` from the repository root
for the fully rendered site:

**[Open the queues, heaps, and scheduling guide](../content/03-queues-heaps-scheduling/_index.md)**

Use these files for the exercises:

- [Lab: Keep the Highest-Risk K](./lab/README.md)
- [Wheel of Misfortune scenarios](./wheel/README.md)

The lab begins with a heap that stores only `k` candidates. The three Wheels
then cover retry decisions, events that return blocked work, and repeated work
across a group. Their production context comes from public GitHub Actions and
Kubernetes reports, design documents, and patches.
