# Evidence Packet 4: Three independent decisions

The active ordering rule is:

```text
priority descending, sequence ascending, ID ascending
```

The current reactivation check is:

```text
blocked.Needs.Kind == event.Kind
```

The readiness check used by an attempt is:

```text
satisfied[blocked.Needs.Kind, blocked.Needs.Key]
```

The active order answers which active repair is next. The reactivation check
asks whether an event makes another attempt worth considering; the readiness
check decides whether the repair can actually run. In the current version, the
category-only reactivation check returns the repair to active work while its
full readiness condition remains false.
