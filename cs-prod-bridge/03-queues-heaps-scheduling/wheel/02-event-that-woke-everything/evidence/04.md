# Evidence Packet 4: Three separate decisions

The active ordering rule is:

```text
priority descending, sequence ascending, ID ascending
```

The current event check is:

```text
blocked.Needs.Kind == event.Kind
```

The readiness check used by an attempt is:

```text
satisfied[blocked.Needs.Kind, blocked.Needs.Key]
```

The active order chooses the next active repair. The event check decides
whether another attempt may be useful. The readiness check decides whether the
repair can run. In the current version, the event check can return the repair
to active work while the full readiness condition remains false.
