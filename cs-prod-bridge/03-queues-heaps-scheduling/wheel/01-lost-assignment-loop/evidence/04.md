# Evidence Packet 4: Acquire-result contract

| Result | What is known | Allowed worker response |
|---|---|---|
| acquired | The assignment is valid and owned by this worker | Run it |
| service unavailable | The assignment state is unknown because the service could not answer | Retry the same assignment later |
| request rejected | The assignment exists, but this request cannot be accepted in its current form | Refresh or correct the request, then retry |
| assignment missing | The named assignment no longer exists | End this ephemeral session so its supervisor can replace it |
| assignment superseded | The assignment now belongs to another generation or worker | End this ephemeral session so its supervisor can replace it |

Retiring a worker is not a punishment for an unhealthy process. An ephemeral
worker is created for one assignment. Once that assignment cannot be acquired,
the session has no remaining useful transition. Its supervisor owns creating a
replacement that can request valid work.
