# Evidence Packet 4: What each acquire result means

| Result | What is known |
|---|---|
| acquired | The assignment is valid and owned by this worker |
| service unavailable | The service could not report the assignment state |
| request rejected | The assignment exists, but the current request was not accepted |
| assignment missing | The named assignment no longer exists |
| assignment superseded | The assignment now belongs to another generation or worker |

The worker is a one-assignment session. Its supervisor can replace a session
when the worker action ends it.

For each result, choose an action from the candidate guide. Explain what would
have to change before another request for the same assignment could succeed.
