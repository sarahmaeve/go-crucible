# Evidence Packet 3: Four members, twelve calls

For group `[a, b, c, d]`:

```text
observe a: request b, c, d
observe b: request a, c, d
observe c: request a, b, d
observe d: request a, b, c
```

The queue ends with four distinct IDs. It still receives twelve calls. After
the first few calls, most calls find an ID that is already present and emit a
log message.

How many calls are necessary to make every member eligible when one member is
already being examined? Which observation could make those calls?
