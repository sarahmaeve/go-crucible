# Evidence Packet 4: Where repetition begins

The simplified control flow is:

```text
for each member observed this round:
    if group is ready:
        for each other member:
            request activation
```

The inner loop is necessary once: one member examined after the group becomes
ready must make its siblings eligible. The outer loop turns that one group-wide
action into one action per member.

`RoundState` is created at the start of a reconciliation round and discarded
at its end. It currently records no fact about whether the group-wide action
has already occurred.
