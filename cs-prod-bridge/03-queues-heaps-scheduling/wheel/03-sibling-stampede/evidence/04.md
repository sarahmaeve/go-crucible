# Evidence Packet 4: Control flow around the sibling loop

The simplified control flow is:

```text
for each member observed this round:
    if group is ready:
        for each other member:
            request activation
```

`RoundState` is created at the start of a reconciliation round and discarded
at its end. It currently records no fact about whether the group-wide action
has already occurred.

Count how many times the inner loop starts. Which fact must be true before it
starts? Which facts can survive between member observations, and which reset in
the next round?
