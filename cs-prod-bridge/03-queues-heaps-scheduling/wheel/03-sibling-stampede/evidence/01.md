# Evidence Packet 1: Queue size hides caller work

Invented counters for one reconciliation round:

| Workload | Activation queue depth | Activation requests | Duplicate-request logs | Unrelated repair dispatched within 128 operations |
|---|---:|---:|---:|---|
| 64 independent repairs | 64 | 64 | 0 | yes |
| one 64-member group | 64 | 4,032 | 3,968 | no |

The activation queue uses an ID set and never stores two entries for one repair.
The local model counts request handling, ID lookup, and one log for each repeat.
It does not model CPU time or heap comparisons.

These measurements belong to the exercise, not the production report.
