# Evidence Packet 2: Growth by group size

Every member requests every other member in one round:

| Members `g` | Activation requests `g(g-1)` | Distinct IDs retained | Repeated requests |
|---:|---:|---:|---:|
| 4 | 12 | 4 | 8 |
| 16 | 240 | 16 | 224 |
| 64 | 4,032 | 64 | 3,968 |
| 256 | 65,280 | 256 | 65,024 |

Doubling `g` approximately quadruples the requests. Queue depth still grows
with `g` because the queue stores each ID only once.
