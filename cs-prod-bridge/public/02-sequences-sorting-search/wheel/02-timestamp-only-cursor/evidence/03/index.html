    Evidence 03: Change the input order

    Two replicas received the same fixed records in different slice orders. Both applied a stable timestamp sort.

    replica A equal-timestamp IDs before sort: 101,103,102,104,105,106
replica A equal-timestamp IDs after sort:  101,103,102,104,105,106

replica B equal-timestamp IDs before sort: 106,102,105,101,104,103
replica B equal-timestamp IDs after sort:  106,102,105,101,104,103

    Stable sorting preserves each replica’s original slice order, so the replicas still disagree. Explain why a timestamp-only token cannot tell the other replica where the previous page stopped in that group.
